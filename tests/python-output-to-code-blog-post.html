Can you work backwards from output to Python code?

Most exercises show you a program and ask for its output. This quiz reverses the challenge: you see the exact output first and identify the Python program that produced it.

The question bank covers arithmetic operators, strings, conditions, loops, lists, dictionaries and functions. Every answer includes a short explanation so that the test also works as a learning activity.

How to attempt the quiz

  1. Choose the timed test or untimed practice mode.
  2. Read the displayed output exactly as shown.
  3. Compare indentation, operators, ranges and data types.
  4. Select the code that produces that output.
  5. Submit your answers and study the explanation for every question.
